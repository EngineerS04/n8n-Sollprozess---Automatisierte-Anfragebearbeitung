# n8n-Sollprozess---Automatisierte-Anfragebearbeitung
# Es soll eine einfache Anfrage lösen können
# Verwendete Tools: 
n8n, Notion, Google Gemini
# Workflow
1. Anfrage einreichen
2. Notion-Wissenssuche
3. KI-Auswertung
4. Passende Lösung? Ja
5. Passende Lösung raussuchen
6. Passende Lösung? Nein
7. Verweis auf Support
